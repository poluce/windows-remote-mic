引导

快捷入口与首次配置向导。

快捷入口与配置
设置向导
  1. ✓
    1. 蓝牙配对
    长按遥控器「主页 + 菜单」键直到指示灯快闪，在 Windows 蓝牙设置中添加并连接 RC003。
  2. ✓
    2. 确认虚拟声卡驱动
    确保已安装 VB-CABLE 虚拟音频驱动（未安装可前往「连接」页或官网一键安装）。
  3. 3
    3. 【关键】绑定 Windows 语音输入麦克风
    点击下方「唤出语音输入条」或按快捷键 Win+H，在语音条的「设置」中将麦克风选择为「CABLE Output」。
  4. 4
    4. 模拟自检与日常使用
    前往「连接」页点击「模拟完整语音链」验证打字上屏；平时长按遥控器语音键即可秒级语音输入。
