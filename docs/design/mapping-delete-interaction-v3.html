按键映射 · 删除 / 禁用交互设计

核心：悬停 / 选中已绑定格子时，右上角出现红色圆圈 ×——点 × 取消关联（删除绑定）；点击格子本体切换禁用/启用。启用态文字为微绿色，禁用时整格红色填充，再次点击恢复。禁用保留记录和动作，× 才是真正删除。

B · 状态流转：删除 / 禁用是两条独立的路
未绑定格子显示 — — 选动作 + 保存 → 已绑定（启用）文字微绿 — 点击格子 → 已禁用红色填充 — 再次点击 → 已绑定（启用）恢复微绿
已绑定（启用） — 点红色 × → 未绑定格子显示 — 或 已禁用 — 点红色 × → 未绑定

编辑已有动作：点击该格子（会先切换一次禁用/启用，同时设为编辑目标）→ 左侧重选动作 → 点「保存此键」，保存后恢复启用并用新动作。想直接删掉就点 ×，一步到位。

C · 三个必须说清的语义
×

× = 取消关联（真正删除）

配置里这条记录被移除，该触发变成未绑定：不触发、不占手势。双击/长按删掉后，单击恢复「松开立即生效」。

作用域：全局作用域删除全局绑定；应用档案作用域删除的是覆盖（回到沿用全局）。

◐

点击 = 禁用 / 启用（保留记录）

只翻转 enabled 标志，动作与条目都保留。启用时文字微绿，禁用时红色填充；禁用期间不触发、手势时序按未绑定处理；再次点击立即恢复。

× 只在悬停 / 选中时出现，矩阵更清爽；红色填充明确表示「被禁用，但配置还在」。

档

应用档案作用域

格子显示的是「这份配置真正生效的绑定」：有覆盖显示覆盖，没有则显示全局（灰调）。× 只删覆盖；点击切换覆盖的启用状态。

没有覆盖的格子不提供 ×，避免误删全局；想让该应用里此键无动作，先保存一条覆盖再禁用。

D · 实现要点（与现有架构对齐）

数据层

  • KeyBinding 新增 enabled: bool（serde 默认 true，旧配置自动兼容）；禁用只改标志，动作不丢。
  • 旧配置里的「其他 → 禁用」动作（ActionKind::Disabled）迁移为未绑定（它本来就不执行动作）。
  • 空列表 = 真的没有绑定；前端修复「空列表回退默认映射」的旧逻辑。

命令与调度

  • clear_mapping_binding(button, trigger)：× 删除；应用档案复用 clear_profile_binding。
  • set_mapping_binding_enabled(button, trigger, enabled)：点击切换；写盘 + dispatcher.update_mapping() 热更新。
  • 调度器：只有 enabled 的绑定参与动作执行与手势判定；禁用条目视同未绑定。
  • 单格删除给 toast + 撤销；所有点击热更新即时生效，无需重启。
  • 前端 CSS：.cell:hover .x / .cell.selected .x 才显示 ×；启用文字用微绿 token，禁用用红色填充。

MVP 范围：全局作用域先落地（悬停/选中出现 ×、点击禁用/启用、启用文字微绿、toast 撤销、空列表修复）；应用档案作用域复用现有覆盖命令，第二步补齐「覆盖层禁用」。本设计稿只描述交互，尚未实现。
