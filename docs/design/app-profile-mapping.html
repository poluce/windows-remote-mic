设计说明

以下内容不属于应用界面，实现时不会出现在产品里。

  • 「拦截 HID 按键信号」已搬到新页面：从「按键映射」移到「通用设置」， 排在「按键映射」之后。点左侧导航可以切过去看。
  • 「按键映射」新增作用范围：选中某个应用后，编辑的是它的覆盖层， 没覆盖的格子自动沿用全局，不必为每个应用重抄整张表。
  • 映射表改成矩阵：行＝按键，列＝单击 / 双击 / 长按。原来的平铺列表只列出 已配置的组合，看不出「哪些还没绑」；矩阵把全部格子摊开，空格显示 —。
  • 麦克风单独一行跨三列：它是 PTT 键，只有按下 / 松开，塞进三个触发列会误导。
  • 颜色含义：蓝底＝这份配置覆盖过，灰字＝沿用全局，—＝未绑定。
  • 点矩阵里的格子即可选中它去编辑；只有选中的格子是被覆盖过的， 向导里才会出现「改用全局」。
  • 状态只在「不一致」时才提示：开关本身就是状态，正常情况不再复读。 只有开关开着、驱动注入却没就绪时，才补一句告警。
  • 待定：长按判定 / 双击间隔要不要也挪到「通用设置」？它们是全局参数， 现在藏在按键映射页的向导里，容易让人以为是逐键设置。
  • 可点的部分：左侧「按键映射」「通用设置」两页、作用范围切换、矩阵格子、 「+ 新建应用」。其余导航页本稿未涉及，点了没反应。
  • 遥控器图形是现有组件，稿里用简图代替；「图标 / 启动方式」暂不进新建对话框。
