## 4. CAPS 解析（payload[0] = `0x0B`）

```text
byte0: opcode 0x0B
byte1-2: version (big-endian)
byte3: codecs (v1.0+)
byte4: interaction (v1.0+)
byte5-6: frame_size (big-endian; 0 -> 120)
byte7+: 扩展/旧版字段
```

- v1.0 特殊：如果 `codecs == 0` 且 `byte4 & 0x03 != 0`，则 `codecs = byte4`，`interaction = 0x03`
- 旧版：`codecs = byte4`
- `selected_codec = 0x02` → 16 kHz，否则 8 kHz
- 本项目只支持 **16 kHz**

**待确认**：interaction 各 bit 含义、扩展字段长度。

## 5. 音频格式

| 项 | 值 | 状态 |
| --- | --- | --- |
| 采样率 | 16 kHz | ✅ |
| 编码 | IMA/DVI ADPCM 4-bit | ✅ |
| 采样顺序 | 高半字节优先 | ✅ |
| 每字节采样数 | 2 | ✅ |
| 默认帧长 | 120 字节（常见 RC003） | ✅（以 CAPS 为准） |
| 帧长变体 | 120 / 126（带同步头）/ 160（Chromecast remote @50fps） | ⚠️ 不同设备/固件有差异 |
| PCM 后处理 | 3 点平滑 + 增益 | ✅（我们已实现） |
