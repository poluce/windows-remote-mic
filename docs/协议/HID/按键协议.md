# HID 按键协议（RC003）

> 状态：社区/实现整理，非官方规范；最终以真机验收为准  
> 关联：`docs/协议/ATVV/协议.md`

## 普通按键走 HID

遥控器普通按键通过蓝牙 HID 键盘报告上报，usage page = `0x07`（Keyboard）。

## 按键 Usage 表

| 物理按键 | HID Usage | 标准性 | Windows 注意 |
| --- | --- | --- | --- |
| 麦克风（F5 回退） | `0x3E` | 标准 | 一般也走 ATVV Control |
| 返回 | `0xF1` | **厂商自定义**（0xE8–0xFF 保留区） | Raw Input / 钩子收不到，需旁路 |
| 确定 | `0x28` | 标准 | ✅ |
| TV | `0x35` | 标准（Launch Media Select） | Raw Input / 钩子收不到，需旁路 |
| 主页 | `0x4A` | 标准 | ✅（实测映射为 `VK_HOME(36)`，不是 `VK_BROWSER_HOME(172)`） |
| 右 | `0x4F` | 标准 | ✅ |
| 左 | `0x50` | 标准 | ✅ |
| 下 | `0x51` | 标准 | ✅ |
| 上 | `0x52` | 标准 | ✅ |
| 菜单 | `0x65` | 标准 | ✅ |
| 电源 | `0x66` | 标准 | ✅ |
| 音量 + | `0x80` | 标准（Keyboard Volume Up） | Raw Input / 钩子收不到，需旁路 |
| 音量 − | `0x81` | 标准（Keyboard Volume Down） | Raw Input / 钩子收不到，需旁路 |
| 静音 | `0x7F` | 标准 | 遥控器无实体键，仅 usage 存在 |

## Windows Raw Input 缺口

- 返回 `0xF1`、TV `0x35`、音量 `0x80/0x81` 在 Windows Raw Input 下缺失（实测）
- 原因：这四个键属于「应用命令类按键」，被 HOGP 层从键盘输入通道分流，Raw Input 和 WH_KEYBOARD_LL 钩子都看不到
- 系统仍认识并原生处理它们（返回 → 浏览器后退、TV → 启动媒体选择、音量 → 系统音量变化，走 WM_APPCOMMAND 应用命令通道，推断待真机验证）
- 可选旁路：Frida/WUDFHost HID-over-GATT 读取（四个键都能捕获到）
- 或者用按键采集工具确认物理签名后再映射

## 按键行为约定

- 支持单击 / 双击 / 长按
- 长按约 550ms，双击窗口约 300ms
- 可配置按键按住重复
- 麦克风键固定走语音链路，不参与普通映射
