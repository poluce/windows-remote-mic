# HID 按键协议（RC003）

> 状态：社区/实现整理，非官方规范；最终以真机验收为准  
> 关联：`docs/协议/ATVV/协议.md`

## 普通按键走 HID

遥控器普通按键通过蓝牙 HID 键盘报告上报，usage page = `0x07`（Keyboard）。

## 按键 Usage 表

| 物理按键 | HID Usage | Windows 注意 |
| --- | --- | --- |
| 麦克风（F5 回退） | `0x3E` | 一般也走 ATVV Control |
| 返回 | `0xF1` | Raw Input 可能收不到，需旁路 |
| 确定 | `0x28` | ✅ |
| TV | `0x35` | ✅ |
| 主页 | `0x4A` | ✅ |
| 右 | `0x4F` | ✅ |
| 左 | `0x50` | ✅ |
| 下 | `0x51` | ✅ |
| 上 | `0x52` | ✅ |
| 菜单 | `0x65` | ✅ |
| 电源 | `0x66` | ✅ |
| 音量 + | `0x80` | Raw Input 可能收不到，需旁路 |
| 音量 − | `0x81` | Raw Input 可能收不到，需旁路 |
| 静音 | `0x7F` | 遥控器无实体键，仅 usage 存在 |

## Windows Raw Input 缺口

- 返回 `0xF1`、音量 `0x80/0x81` 在 Windows Raw Input 下可能缺失
- 可选旁路：Frida/WUDFHost HID-over-GATT 读取
- 或者用按键采集工具确认物理签名后再映射

## 按键行为约定

- 支持单击 / 双击 / 长按
- 长按约 550ms，双击窗口约 300ms
- 可配置按键按住重复
- 麦克风键固定走语音链路，不参与普通映射
