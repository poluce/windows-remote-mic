# 发布说明（Windows 打包）

在 **Windows** 机器上构建桌面安装包。

## 前置条件

- Rust（rustup + MSVC Build Tools，建议与 CI 一致：`rustup update stable`）
- Node.js 20+
- WebView2（Windows 11 自带，Windows 10 安装时可选自动下载）

## 桌面开发窗口

```powershell
npm install
npm run tauri dev
```

## 构建安装包

```powershell
# 1) 准备虚拟 HID 驱动 bundle（放进 src-tauri/windows/driver/，已被 gitignore）
powershell -ExecutionPolicy Bypass -File scripts/prepare-vhid-bundle.ps1

# 2) 构建（beforeBuildCommand 会自动执行 npm run build:installer，
#    其中包含前端构建 + stage VB-CABLE 助手脚本 + MCP sidecar）
npm run tauri:build
```

产物位置（Cargo workspace 根 `target/`）：

```text
target/release/bundle/nsis/
└── Remote.Mic_<version>_x64-setup.exe
target/release/
└── remote-mic.exe                      # 免安装单文件
```

> 安装包为 **全机安装（perMachine）**，需要管理员权限：一次 UAC 完成应用 + 虚拟 HID 驱动安装，
> 自动带简体中文 + English。安装器同时把 VB-CABLE **助手脚本**放到 `<安装目录>\scripts\`
> （VB-CABLE 本体不随包分发，用户之后在应用内点「下载并安装 VB-CABLE」触发官方安装程序，安装后需重启）。
> 虚拟 HID 驱动为测试签名，安装器会自动把随包证书装入本机信任库；首次连接遥控器时
> HOGP 旁路注入可能再弹一次 UAC。

## 校验安装包

```powershell
Get-FileHash -Algorithm SHA256 .\target\release\bundle\nsis\*.exe
Get-FileHash -Algorithm SHA256 .\target\release\remote-mic.exe
```

GitHub Release 会附带 `SHA256SUMS.txt`，可下载后校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## 签名说明

- 当前为未签名构建，首次运行 SmartScreen 会提示「未知发布者」，属预期。
- 后续可接入 Authenticode 签名（`bundle.windows.digestAlgorithm` / `certificateThumbprint` 等）。

## GitHub Actions 自动出包

打 tag（如 `v0.6.2`）或手动触发 `Release Windows Build` 工作流后，Actions 会自动：

1. 准备并校验虚拟 HID 驱动 bundle；
2. 准备并校验 VB-CABLE 助手脚本；
3. 执行 `npm run tauri:build`；
4. 用 7-Zip 解包验证 VB-CABLE 脚本确实嵌入了安装包；
5. 生成 `SHA256SUMS.txt`，创建 GitHub Release 并上传
   `Remote.Mic_<version>_x64-setup.exe`、`remote-mic.exe`、`SHA256SUMS.txt`。

发版流程（版本号三处同步、CHANGELOG、tag）见 `CHANGELOG.md` 顶部说明与 `AGENTS.md` §9。
